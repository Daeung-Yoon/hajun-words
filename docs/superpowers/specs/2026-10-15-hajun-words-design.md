# 하준 영어단어 앱 설계서

작성일: 2026-10-15
상태: 설계 승인 대기

## 1. 목적과 배경

초등학교 6학년 아들(이하 "아이")이 학원 영어 단어 시험을 준비하도록 돕는 개인용 앱.

- 아이는 수학·과학적 사고와 독서량이 강점이고, 독해·말하기·듣기·쓰기가 모두 된다.
- 약점은 맥락 없는 나열 암기. 학원 시험은 월·수·금, 약 30단어, 단어당 한국어 뜻 3~4개를 전부 써야 한다.
- 따라서 앱은 "뜻 목록 암기"가 아니라 **핵심 의미에서 뜻이 파생되는 구조**를 보여주고, 아이의 강점인 독해·논리로 단어를 익히게 한 뒤, 시험 형식에 맞춘 인출 연습으로 마무리한다.

### 성공 기준

- 학원 단어 시험 점수가 오른다.
- 아이가 하루 10~15분을 스스로 넘긴다.

## 2. 사용자와 운영 모델

| 역할 | 하는 일 |
|------|---------|
| 아이 | 폰 또는 데스크탑 브라우저에서 앱을 열어 모드를 골라 공부 |
| 아버지 | 단어장 사진을 넣고 Claude Code 명령으로 콘텐츠 생성, 푸시, 학원 점수 입력 |

- 사용자는 한 명. 로그인·회원가입·서버 없음.
- 폰과 데스크탑은 **브라우저 PWA 하나**로 해결. 폰은 홈 화면에 추가해 앱처럼 사용.
- 진도는 기기마다 따로 저장. 기기 간 동기화는 하지 않으며, 필요하면 내보내기·가져오기로 수동 이동.
- 앱 자체는 LLM을 호출하지 않는다. 콘텐츠는 아버지 PC의 Claude Code가 만든다.

## 3. 데이터 단위: 단어 뱅크와 범위

- **단어 뱅크**: 단어장 한 권 분량의 연속된 단어 목록. 사진 여러 장이 하나의 뱅크로 합쳐지며, 각 단어는 번호(1, 2, 3…)와 출처 라벨(Day 또는 페이지)을 가진다. 사진 순서가 번호 순서. 사진을 추가하면 뒤에 이어 붙는다. 뱅크는 여러 개 둘 수 있다.
- **범위**: 뱅크 안의 시작~끝 번호 구간. 시험마다 아이(또는 아버지)가 앱에서 범위만 바꾼다. 저장한 범위에는 이름(날짜 + Day)이 자동으로 붙고, 기록 그래프의 가로축과 학원 점수 입력 단위가 된다.
- 단어별 레벨은 범위와 무관하게 단어 자체에 붙는다. 누적 복습 범위를 잡아도 이미 확실한 단어는 덜 나온다.

## 4. 화면 구성

### 4.1 홈
- 상단 "이번 범위" 카드: 범위 이름(예: `Day 5~6 (단어 121~180)`), 단어 수, 레벨 분포 막대(모름/익숙/확실).
- 카드를 누르면 범위 설정 화면: Day 단위 선택 또는 단어 번호 직접 입력, 최근 범위 목록, "지금까지 전부" 버튼.
- 모드 버튼 6개 격자. 각 버튼에 소요 시간 힌트.
- 하단: 연속 공부 일수, 오늘 푼 문제 수.

### 4.2 모드 (모두 현재 범위 단어로 동작)

| 모드 | 내용 | 기록 |
|------|------|------|
| 파생 트리 | 단어 카드. 가운데 핵심 의미, 사방으로 뜻 가지, 가지마다 bridge 설명·예문·영영 뜻. 발음 버튼. 그림이 있으면 트리 위에 표시. 아이가 저장한 "내 문장"도 표시 | 열람 여부만 |
| 예문 빈칸 | 영어 문장에 빈칸. 보기 4개 중 선택 또는 직접 입력(설정 토글). 뜻마다 문장이 있어 한 단어가 여러 번 나옴 | 채점 |
| 뜻 고르기 | 밑줄 문장을 보고 한국어 뜻 4개 중 선택. 교재 뜻을 보기로 사용 | 채점 |
| 영영 매칭 | 단어 5개와 영어 정의 5개 짝짓기 | 채점 |
| 문장 만들기 | 단어와 뜻 하나를 주고 아이가 문장 입력·저장 | 채점 없음 |
| 학원 모의시험 | 단어를 보고 한국어 뜻 전부 입력. 100점 환산 | 채점 |

### 4.3 기록
- 단어별 레벨 목록(필터: 모름만).
- 범위별 그래프: 앱 모의시험 점수와 학원 점수 선 2개.
- 배지 목록.

### 4.4 설정 (아버지용)
- 학원 점수 입력(범위별), 진도 초기화, 내보내기(JSON 다운로드), 가져오기(파일 선택), 빈칸 모드 입력 방식 토글.

## 5. 데이터 구조

### 5.1 콘텐츠: 뱅크 JSON (`public/content/banks/<bank-id>.json`)

```json
{
  "id": "wordmaster-6",
  "title": "워드마스터 초등 6",
  "words": [
    {
      "id": "run",
      "no": 121,
      "source": "Day 5",
      "word": "run",
      "pos": "v., n.",
      "ipa": "/rʌn/",
      "core": { "ko": "끊김 없이 쭉 흘러가다", "en": "to keep moving without stopping" },
      "senses": [
        {
          "ko": "달리다",
          "en": "to move quickly on foot",
          "bridge": "사람이 쭉 가면",
          "example": "She runs every morning before school.",
          "blank": "She ____ every morning before school."
        }
      ],
      "koGenerated": false,
      "image": null,
      "etymology": null
    }
  ]
}
```

- `core`: 파생 트리의 중심. `bridge`: 핵심에서 각 뜻으로 가는 한 줄 설명.
- `ko`: 교재에 적힌 뜻을 그대로. 모의시험 채점 기준. 사진에 뜻이 없어 생성했으면 `koGenerated: true`.
- `blank`: 생성 단계에서 미리 만든다. 앱은 형태 변화를 처리하지 않는다. 빈칸 표기는 `____` 고정.
- `image`(경로), `etymology`(어근 설명)는 선택. 비어 있으면 화면에서 생략.
- `id`는 철자 소문자. 같은 단어가 다른 Day에 또 나오면 항목을 추가하지 않고 `source`에 라벨을 덧붙인다(`"Day 5, Day 12"`).
- 발음은 Web Speech API. `ipa`는 표시용.
- `public/content/index.json`에 뱅크 목록(`id`, `title`, 파일 경로, 단어 수)을 둔다.

### 5.2 진도: IndexedDB (Dexie)

| 테이블 | 키 | 내용 |
|--------|----|------|
| `wordState` | 단어 id | 레벨(0~3), 연속 정답 수, 마지막 학습 시각, 모드별 정답/오답 횟수 |
| `mySentences` | 자동 | 단어 id, 뜻 index, 문장, 저장 시각 |
| `ranges` | 자동 | 이름, 뱅크 id, 시작·끝 번호, 생성일, 모의시험 최고 점수, 학원 점수 |
| `sessions` | 자동 | 모드, 범위 id, 시각, 맞힌 수/전체 (출석·오늘 푼 문제 수 계산용) |
| `badges` | 배지 id | 획득 시각 |
| `settings` | 키 | 현재 범위 id, 빈칸 입력 방식 등 |

- 내보내기는 위 테이블 전체를 JSON 한 파일로. 가져오기는 덮어쓰기.
- 콘텐츠와 진도는 완전히 분리. 뱅크를 재생성해도 진도가 유지되고, 진도를 초기화해도 콘텐츠는 그대로.

## 6. 학습 알고리즘

### 6.1 단어 레벨 (0~3)
- 0 모름, 1 본 적 있음, 2 익숙, 3 확실. 초기값 0.
- 파생 트리 열람 → 최소 1.
- 채점 모드에서 정답 → 연속 정답 수 +1. 2회 연속이면 레벨 +1(최대 3), 연속 정답 수 0으로 리셋.
- 오답 → 연속 정답 수 0, 레벨 1(이미 0이면 0 유지).
- 레벨 3이라도 7일 이상 미학습이면 "흐려짐" 표시. 레벨은 깎지 않고 출제 가중치만 올린다.

### 6.2 출제 (채점 모드 공통)
- 가중치: 레벨 0 → 4, 1 → 3, 2 → 2, 3 → 1. 7일 이상 미학습이면 +2.
- 한 회차 10문제 고정. 끝나면 결과 화면(맞힌 수, 레벨 오른 단어)과 "한 번 더".
- 한 회차에 같은 단어는 한 번. 단, 뜻이 다른 문장은 허용(빈칸·뜻 고르기).
- 오답 보기는 같은 범위의 다른 단어·뜻에서. 범위가 4개 미만이면 뱅크 전체에서 보충.
- 범위 단어가 10개 미만이면 회차 길이는 단어 수.

### 6.3 모드별 채점
- 빈칸·뜻 고르기: 즉시 정오 표시. 오답이면 정답과 해당 뜻의 영영 정의 표시. 직접 입력은 대소문자·앞뒤 공백 무시 정확 일치.
- 영영 매칭: 5쌍. 틀린 쌍만 다시 섞어 재시도. 첫 시도에 맞힌 단어만 정답으로 기록, 나머지는 오답.
- 문장 만들기: 채점 없음. 저장하면 레벨 1 이상 보장.
- 모의시험: 범위 전체, 번호 순/섞기 선택. 단어당 뜻 개수만큼 입력칸. 채점은 공백·구두점 제거 후 정확 일치, 순서 무관. 단어 점수 = 맞힌 뜻 수 / 뜻 수. 총점 = 단어 점수 합 / 단어 수 × 100, 소수점 반올림. 단어 단위로 전부 맞혔을 때만 정답, 하나라도 틀리면 오답으로 레벨 반영. 종료 후 틀린 단어 목록에서 파생 트리로 바로 이동.

### 6.4 출석·배지
- 하루에 채점 모드 1회차 이상 완료하면 출석. 자정(기기 로컬 시간) 기준. 하루 건너뛰면 연속 일수 0.
- 배지: 첫 회차 완료, 연속 3·7·14·30일, 범위 전체 레벨 3, 모의시험 100점, 내 문장 10개.

## 7. 콘텐츠 파이프라인

### 7.1 폴더
```
photos/inbox/                      새 사진
photos/done/                       처리 완료 사진 (자동 이동)
public/content/banks/              뱅크 JSON
public/content/index.json          뱅크 목록
public/content/images/             선택 그림
.claude/skills/add-words/SKILL.md  생성 명령
scripts/validate.ts                검증
```

### 7.2 `/add-words` 동작
1. `photos/inbox/` 사진을 파일명 순으로 읽어 단어·품사·교재 한국어 뜻·출처 라벨(Day/페이지) 추출.
2. **1차 확인**: 추출 목록을 표로 보여주고 멈춘다. 승인 후 진행.
3. 단어 10개 단위로 `core`, `senses`(bridge·example·blank·en), `ipa`, `etymology`(해당 시) 생성해 뱅크 JSON에 추가. 이미 있는 단어는 `source`만 덧붙임. 대상 뱅크는 인자로 지정, 없으면 새로 만든다.
4. `npm run validate` 실행. 실패한 단어만 재생성.
5. **2차 확인**: 요약(단어 수, 뜻 개수 분포, 샘플 3개) 표시. 사진을 `done/`으로 이동. `index.json` 갱신.

### 7.3 생성 품질 규칙 (SKILL.md에 고정)
- 한국어 뜻은 교재 표기 우선. 없을 때만 생성하고 `koGenerated: true`.
- 예문은 초등 고학년 수준, 10단어 안팎, 해당 뜻이 문맥만으로 드러나게.
- 핵심 의미는 가지 전부를 설명할 수 있을 때만. 억지로 묶이지 않는 뜻은 `bridge`에 "다른 뿌리"라고 적고 `etymology`로 보완.
- 영영 뜻은 Learner's dictionary 수준의 쉬운 영어.

### 7.4 검증 (`scripts/validate.ts`)
- `src/content/schema.ts`의 zod 스키마로 검사(앱과 공유).
- 중복 id, 번호 연속성, 각 `blank`에 `____` 포함, `senses` 1개 이상, `index.json`과 파일 일치.

### 7.5 그림 (선택)
- `public/content/images/<id>.png`를 넣고 `image` 필드에 경로를 적는다. 별도 명령 없음.

## 8. 기술 스택

- Vite + React + TypeScript. 라우팅 `react-router`. 상태는 React 내장.
- PWA: `vite-plugin-pwa`. 뱅크 JSON 포함 오프라인 캐시. 뱅크가 바뀌면 "새 단어가 왔어요" 갱신 안내.
- 진도: `Dexie`.
- 스키마: `zod`. 타입은 `src/content/schema.ts` 한 곳.
- 그래프: `recharts`.
- 발음: Web Speech API, `en-US` 우선.
- 스타일: CSS 변수 기반 직접 작성. 모바일 우선, 데스크탑은 가운데 최대 폭 제한. 다크 모드.
- 테스트: Vitest. `src/study/`의 순수 로직은 단위 테스트 필수. 화면은 핵심 흐름만 React Testing Library.
- 패키지 이름 `hajun-words` (폴더명이 한글이므로 별도 지정).

## 11. 오류 처리

- 뱅크 JSON 로딩 실패: 오프라인 캐시가 있으면 그걸 사용, 없으면 "단어장을 불러올 수 없어요" 화면과 재시도 버튼.
- 스키마 불일치: 콘솔에 상세, 화면에는 뱅크 이름과 "아빠에게 알려주세요" 메시지. 앱이 멈추지 않도록 해당 뱅크만 제외.
- Web Speech 미지원 또는 음성 없음: 발음 버튼 비활성화 및 툴팁.
- 가져오기 파일 형식 오류: 기존 진도 유지, 오류 메시지만 표시.
- IndexedDB 사용 불가(사생활 보호 모드 등): 메모리 저장으로 동작하되 "진도가 저장되지 않아요" 배너.
